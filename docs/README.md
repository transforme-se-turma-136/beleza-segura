# Documentação

Esta pasta reúne os documentos acadêmicos e técnicos do BelezaSegura.

## Arquivos iniciais

1. `01-documentacao-do-produto.pdf` — ideação, escopo, modelo de negócio, monetização e requisitos;
2. `02-termo-de-abertura.pdf` — objetivos, justificativa, escopo, cronograma, responsabilidades, riscos e critérios de sucesso;
3. `03-apresentacao-do-projeto.pdf` — apresentação visual do problema, da solução, do diferencial e do modelo de negócio.

Novas decisões técnicas devem ser registradas em arquivos Markdown para facilitar o histórico de alterações no Git.
